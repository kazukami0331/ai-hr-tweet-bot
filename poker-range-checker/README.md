# ポーカーレンジ確認アプリ(トーナメント基礎)

GLORY ACADEMY アプリのレンジ表スクリーンショット(59枚)を元に、
テーマ一覧 → テーマ詳細 → レンジ表 の階層構造ごと再現したレンジ確認アプリ。

## 使い方

`index.html` をブラウザで開くだけで動きます(ビルド・サーバー不要)。
GitHub Pages で公開する場合はこのディレクトリを公開対象にしてください。

- テーマ(9カテゴリ)→ 状況(24レンジ)→ 13×13 レンジ表
- セルをタップするとアクション頻度(%)を表示
- 混合戦略セルは元アプリ同様、セル内の色分割(幅=頻度)で表示

## データの出所と精度

- `data.js` の `RANGE_DATA` はスクリーンショットからの**ピクセル解析**で生成
  (目視転記ではない)。セル色は元アプリの固定パレットと完全一致で分類:
  - レイズ `rgb(234,153,153)` / オールイン `rgb(202,18,97)` /
    コール `rgb(89,185,102)` / フォールド `rgb(51,53,59)`
- 同一画面の重複スクショ(2組)で抽出結果が169セル完全一致することを確認済み
- 描画アニメーション途中で撮られた「上半分」スクショは検出して除外し、
  完成状態のスクショのみを採用
